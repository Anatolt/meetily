# Meetily Dark

An unofficial fork of [Meetily](https://github.com/Zackriya-Solutions/meetily) with System, Light, and Dark appearance modes. Meeting audio and transcription can stay on your device.

[Download for macOS or Windows](https://anatolt.github.io/meetily/) · [Build from source](docs/BUILDING.md)

```bash
git clone https://github.com/Anatolt/meetily.git
```
