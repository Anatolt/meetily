Что внутри

Коротко о сборке

Meetily - приложение для локальной записи, транскрибации и подготовки заметок встреч. Эта страница относится только к неофициальной сборке с изменениями темной темы из upstream PR 575.

  • Темная тема

    Сборка основана на работе из PR 575: tri-state предпочтение темы приложения.

  • Локальная обработка

    Meetily ориентирован на локальную транскрибацию и хранение данных на устройстве.

  • Открытый исходный код

    Код доступен в GitHub-репозитории, лицензия проекта - MIT.

Перед установкой

Системные требования

macOS

  • Mac с Apple Silicon.
  • Достаточно места для приложения и локальных моделей транскрибации.
  • Разрешения macOS на микрофон и запись системного звука, если они нужны вашему сценарию.

Windows

  • 64-битная Windows.
  • Достаточно места для приложения и локальных моделей транскрибации.
  • Разрешение на доступ к микрофону и аудиоустройствам.

Неподписанное приложение

Как открыть после загрузки

Сборка не подписана официальным сертификатом. Операционная система может показать предупреждение при первом запуске.

macOS

  1. Откройте DMG и перенесите Meetily в папку Applications.
  2. Если Gatekeeper блокирует запуск, откройте System Settings - Privacy & Security.
  3. Подтвердите запуск приложения, только если вы доверяете этой сборке.

Windows

  1. Запустите EXE или MSI установщик.
  2. Если SmartScreen показывает предупреждение, проверьте источник файла.
  3. Продолжайте установку только если вы доверяете этой сборке.
