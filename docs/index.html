What this build adds

The same local-first Meetily, with a better fit.

Meetily records, transcribes, and turns meetings into notes with processing designed to stay on your device. This community build adds the appearance work from upstream PR #575.

  • Three appearance modes

    System, Light, and Dark are available from one clear setting.

  • Local-first workflow

    Keep meeting recordings, transcripts, and models on your computer.

  • Open source

    Inspect the source, the theme changes, and the build workflow on GitHub.

Before you install

System requirements

macOS

  • A Mac with Apple Silicon.
  • Storage for the application and local transcription models.
  • Microphone and audio permissions for the features you use.

Windows

  • 64-bit Windows on an Intel or AMD processor.
  • Storage for the application and local transcription models.
  • Microphone and audio-device permissions.

Unsigned packages

Opening the app for the first time

These community packages are not signed with an Apple Developer or Windows code-signing certificate, so your operating system may display a warning.

macOS

  1. Open the DMG and drag Meetily into Applications.
  2. If blocked, open System Settings → Privacy & Security.
  3. Choose Open Anyway only after confirming you trust this build.

Windows

  1. Run the Setup EXE, or use the MSI for managed installation.
  2. If SmartScreen appears, check the filename and GitHub source.
  3. Continue only after confirming you trust this build.
